What this example demonstrates

  • HTML provides the element where the map appears.
  • CSS gives the map a visible size and styles the page.
  • JavaScript creates the map and adds a marker and popup.
  • Coordinates determine the location shown on the map.

Your turn: Open js/script.js and change the latitude, longitude, and popup text to a location you choose. Save and refresh the page.
